\section{Estimator and finite-resolution target}

At each active Cartesian cell, with $X^i=x^i-x^i_{\rm p}$,
\begin{equation}
q_{\rm loc}=-\frac16 X^k\gamma^{ij}\partial_k\gamma_{ij}
           =-\frac16 X^k\partial_k\ln\det\gamma.
\end{equation}
The physical metric derivative is reconstructed from $\Psi$, $\Phi$, the
current reference frame/coframe, and analytic reference jets.  The production
controller performs no spatial finite difference, ray interpolation, radial
binning, or interpolation to $r=0$.

For actual cells in $2h\leq r<8h$,
\begin{equation}
w_i=\left(\frac{2h}{r_i}\right)^3,\qquad
q_{\rm est}=\frac{\sum_iw_iq_{{\rm loc},i}}{\sum_iw_i}.
\end{equation}
Variance, effective sample size, extrema, and count are recorded.  The exact
finite-grid target $q_T^{\rm analytic}(h)$ applies the identical cell set and
weights to the provider-derived finite-radius exponent.  The controller is not
told that the continuum limit is one.

The independent relative diagnostic is
\begin{equation}
\epsilon_G=-\frac16X^k(G^{-1})^{IJ}\bar\theta^K{}_k\Phi_{KIJ},
\qquad q_{\rm phys,loc}=q_{\rm ref,loc}+\epsilon_G.
\end{equation}
The identity passes analytic/random-state tests; $\epsilon_G$ is recorded and
is not forced to zero.

\subsection{Puncture-stencil exclusion}

Every primary field, constraint, common-ADM, exponent, gauge, and cache-oracle

\section{q-controlled reference and reprojection}

Only the exact trumpet spatial Cholesky factor changes:
\begin{equation}
W(r)=e^{-(r/R_G)^2},\qquad
L(q)=L_T\exp[-(q-1)W(r)\ln(r/M)],\qquad R_G=3M.
\end{equation}
Lapse, shift, finite-radius profiles, and $R_G$ remain fixed.  At $q=1$ the
provider agrees with $L_T$ to binary64 accuracy.

For $q\ne1$, the same physical stationary coordinate metric and derivatives
are projected into the current tetrad.  The resulting $\Pi$ is generally
nonzero because the physical shift advects the relative metric.  Reconstruction
errors are $4.44\times10^{-16}$ for the metric and
$9.86\times10^{-16}$ for its derivative; the smallest deliberately nontrivial
$|\Pi|$ is 0.125187.  The ordinary-GH $\hat H$ and stationary improved-driver
$\theta$ are likewise projected and subtract the matching current-reference
baseline.  Their source-unit errors are $1.11\times10^{-16}$ and
$2.22\times10^{-16}$.

Nonperiodic boundaries project this same physical metric and gauge state at
the stage values $(q,\dot q,\ddot q)$.  They never reuse
$\Psi=\eta,\Pi=\Phi=0$ for a mismatched reference.

\section{Controller and RK coupling}

The replicated state $(q,\dot q)$ obeys
\begin{align}
\dot q &= q_{\rm dot},\\
\dot q_{\rm dot} &= -2\zeta\omega_q q_{\rm dot}
                    +\omega_q^2(q_{\rm est}-q),
\end{align}
with a smooth acceleration limiter.  Defaults are $\zeta=1$,
$\omega_qM=0.5$, $q\in[0.5,2.5]$, and $|\dot q|M\leq0.25$.  State-bound
crossing fails the run; there is no clipping-and-continuation path.

The PDE and controller use identical RK stages.  A stage copies the PDE and
controller state, builds a lightweight current-q spatial snapshot, measures
$q_{\rm est}$, computes $\ddot q$, builds the full two-jet cache with the same
generation, computes the Ref-GH/gauge RHS, and performs the common update.
Generation assertions reject stale reference use.  Restart headers persist the
controller state, generation, frozen state, and estimator diagnostics.

The manufactured scalar histories verify sign, critical damping, slowly
varying response, exact restart continuation, prescribed C2 pulses, and absence
of clipping.  Critical-history error is approximately $1.03\times10^{-15}$;
the Aurora/SYCL prescribed oracle error is $3.02\times10^{-9}$.
