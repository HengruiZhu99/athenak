# Compact transition-path diagnosis artifacts

This directory contains only compact, source-qualified evidence. It does not
contain large field dumps or restart files.

- `reference_path_scan.tsv`: the complete 3 path x 9 time x 7 measure CPU scan.
- `reference_path_scan_summary.json`: scaling fits and selected comparisons.
- `reference_path_comparison.tsv`: compact shrinking/frozen/fixed-core table.
- `local_source_unit.log`: existing source and Minkowski oracles on current source.
- `local_maxloc_smoke.tsv`: one-cycle maximum-value/location telemetry check.
- `local_medium_mesh_structure.dat` and `local_medium_mesh_stdout.txt`: the
  authoritative local 34-block medium tree audit.

- `aurora/job_8776204_medium/`: compact eight-tile build, mesh, frozen-pass,
  fixed-core-failure, and partial post-failure-wrapper evidence. No restarts.
- `aurora/job_8776416_fixed_width_debug12/`: compact 12-tile mapping and
  fixed-width invalid-timestep failure evidence. No restarts.
- `aurora/medium_path_summary.{json,tsv}`: header-aware normalized histories,
  final status, and max-location records generated by
  `scripts/ref_gh/analyze_transition_path_medium.py`.
- `aurora/job_8776454_rate12/`: 12-tile fixed-core tau-8 and tau-16 rate
  ablations, including real restart evidence through `t=4M`.
- `aurora/job_8776594_standard12/`: current-source PVC build/unit/Minkowski
  evidence and the failed original-path standard-Phi discriminator.
- `aurora/job_8776640_tau8_coarse/`, `job_8776641_tau8_medium/`, and
  `job_8776642_tau8_fine/`: compact 12-tile three-resolution histories,
  mappings, mesh audits, status, timing, and hashes. No restart files.
- `aurora/medium_decision_summary.{json,tsv}`: all medium discriminators in a
  single normalized decision table.
- `aurora/tau8_resolution_gate.{json,tsv}` and
  `tau8_resolution_gate_decision.md`: machine-readable convergence data and
  the bounded Phase-8 decision.
