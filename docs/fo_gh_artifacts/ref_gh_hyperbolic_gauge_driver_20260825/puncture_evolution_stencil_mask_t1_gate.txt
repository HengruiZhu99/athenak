Mask correction
---------------
For fourth-order Ref-GH, centered first derivatives reach two cells but the
enabled sixth-derivative Kreiss-Oliger operator reaches three.  The earlier
radius-two exclusion therefore did not cover every evolution stencil.  Source
histories and stationary/perturbed diagnostics now use

  fd_order/2 + (dissipation > 0 ? 1 : 0).

The offline analyzer requires an explicit maximum stencil radius and rejects a
target if any tensor-interpolation source cell has a support box containing the
puncture.  All results below use radius three.  This is a diagnostic correction;
the evolved equations and field data are unchanged.
