# Held compact-root full derivative one-shot launcher

This fresh standard-library source binds the separate full compact-root candidate.
It has not been imported, syntax-checked or executed. The preserved v2 outer
launcher, original full v1/v2 candidates, admission failure and timing/compact
pilot bundles remain byte-identical. A byte-exact source-history copy and an
explicit rebinding/progress-check diff are included here.

The scientific full settings are unchanged: 80/110 digits; native and analytic
control levels 16,32,64 with mixed 64x32/32x64; seven initial points; original
1e-10 convergence/control/initial/trace, 1e-30 precision, 1e-50 local identities,
1e-40 absolute root and 1e-55 bracket-width thresholds. The native graphs select
the independently reviewed compact-root subclass; analytic controls use their
unchanged closed-form roots. Logging wrappers call each root once and then add
standard-library progress accounting. Source/jet failures after a root call are
not classified as successful rays by the logger. The child requires the original
scientific keys to equal the pinned original recipe and the completed compact
pilot to be PASS (480 rays,24 groups,38344 checks). These source-level distinctions
must not be interpreted as completed full numerical checks.

Only derivative-invocation001 and derivative-attempt001 in this fresh prefix may
be created. Existing paths are refused without mutation. The launcher takes only
--authorization. Root must provide its own exact absolute authorization path,
matching outer source pins, candidate source index, seven child source pins,
sole paths, expected counts, root-call inventory and cost declaration. The
included false authorization schema is not a release. No child is invoked before
all source/dependency/runtime pins and explicit root admission are checked.

The inventory has 164 unique protected paths: three outer sources/plans, one
candidate index, eleven candidate files, sixty dependencies,87 mpmath source
files, one resolved interpreter and one root authorization. The interpreter is
metadata only; the remaining163 files are copied byte-exact to source-before.
The candidate's successful compact pilot inputs/outputs are among dependencies.
All pins are rehashed after the child. Complete child stdout/stderr, true exit
code, partial outputs, traceback and elapsed time are preserved even on failure.
Output hashes are checked before and after outer saved-receipt readback. No retry,
warning filter, source edit, threshold relaxation or resumption is implemented.

The full scientific count is100 native rows,100 analytic control rows,28 initial
limit rows and2360 scientific checks. Completed-root bookkeeping independently

Use the pinned venv Python with -B, bytecode off and BLAS/VECLIB1; unset
PYTHONPATH/PYTHONHOME/PYTHONWARNINGS. All NPZ/NPY and JSON/JSONL larger than1MiB
are tagged large_payload in source metadata. They are still protected and copied

The gate concerns scalar values and first/second inertial derivatives at fixed
reference events. It does not perform an inverse map, native target-time coverage,
Jacobian/caustic analysis, operator/spectrum/propagation/native evolution, lower
order Z4 stability proof or BH gauge selection. The user's later wormhole-to-
trumpet goal retains the Minkowski reference throughout and remains separate.
