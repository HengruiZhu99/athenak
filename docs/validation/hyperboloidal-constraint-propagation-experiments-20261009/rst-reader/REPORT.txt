Read-only binary64 native restart reader gate

Scope: one uniform root block, 3D even dimensions, vacuum hyperboloidal Z4c,
no trackers/other physics/refinement, native little-endian binary64 ABI.
No tracked changes, native run, executable rebuild or frozen-archive edits.

API: import restart_reader; d=restart_reader.read_rst(path)
d['u'] is a read-only numpy ndarray/memmap view with shape(25,nz,ny,nx),
including ghosts. d['time'],d['dt'],d['cycle'] retain exact binary values.
d['parameters'] maps section/key to final assignment strings. Full metadata,
named fields, offsets, active_data (box interior only), and exact shape remain.
The spherical PDE mask still must be applied. align_with_bin aligns the RST
storage view to a BIN output index range without flattening/permutation.

Production writer/readers, structs/config, variable order and actual ABI
are hash-checked. C++ sizeof/offsetof probe: Real8,int4,float4,uint64 size8,
RegionSize72 (9Reals),RegionIndcs76 (19ints),LogicalLocation16 (4int32),
nz4c25,LayoutRight(m,n,k,j,i). Parameter input ends at <par_end> newline.
Header after that has two ints, RegionSize, two RegionIndcs, time/dt double,
cycle int, logical location/cost, Z4c last_output_time double, uint64 data_size.
For nmb1, data starts parameter_header_end+288 bytes. Ghosted shape is
(25,N+2ng,N+2ng,N+2ng); N24/ng3 gives25x30x30x30 doubles. Data_size and exact
EOF are enforced; no offset is guessed from a filename or array match.

Checked87 complete RST/BIN pairs: all81 baseline finite-pulse snapshots
through exactt2/cycle4676, plus3 baseline-reference and3 stage-reference.
Exact time/cycle, box dimensions/indices/geometry and spherical masks agree.
All25 active double fields cast to float32 match corresponding BIN bits,
