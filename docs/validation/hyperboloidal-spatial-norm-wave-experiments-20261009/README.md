# Frozen spatial-norm and coupled-wave evidence

See [the scientific report](../../hyperboloidal-spatial-norm-wave-audit.md)
and `catalog.json`. The native gauge candidate fails pulse acceptance.
The coupled two-field wave decays on tested grids but establishes no Z4c or
discrete energy theorem. Both BH directories contain initial compatibility
checks only; no BH evolution or trumpet transition is claimed.

Sources and receipts are copied byte-for-byte, including retained failed
symbolic-assertion evidence. Their formatting is deliberately preserved and
they are outside production targets. Executables, matrices, eigenvectors,
point arrays and native binary/restart outputs stay local with hashes.

The collector is preserved in `collection-source.py`. Its input directory
names refer to the ignored research workspace. Reproduction requires that
workspace or rebuilding the archived sources with the recorded commands.
The catalog distinguishes launch HEAD from compiled production source.
