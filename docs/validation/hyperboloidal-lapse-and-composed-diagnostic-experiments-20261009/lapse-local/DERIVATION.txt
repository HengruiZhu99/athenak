Let h=alpha_ref>0, G_i=partial_i h, W=W_gauge, c=1-W, and delta beta=beta-beta_ref.
The added REGULAR lapse source is

  Delta Falpha = -c sum_i[(beta_i-beta_ref_i)+beta_i(alpha-h)/h] G_i
               = -c[(alpha/h)beta-beta_ref] dot G.

The old advection beta dot grad alpha - beta_ref dot G therefore becomes

  c beta dot(grad alpha-alpha G/h)
    +W[beta dot grad alpha-beta_ref dot G]
  =c alpha beta dot grad log(alpha/h)
    +W[beta dot grad alpha-beta_ref dot G].

falloff or a new physical-P trace definition. The old conformal-Q lapse branch
already uses log-relative advection, but its trace/pole source differs. Searches
of prior documentation and scratch sources found no exact prior test of this
physical-P hybrid. The authoritative baseline locations are layer_gauge.hpp
lines85-110, docs/hyperboloidal-layer.md lines156-169 and
