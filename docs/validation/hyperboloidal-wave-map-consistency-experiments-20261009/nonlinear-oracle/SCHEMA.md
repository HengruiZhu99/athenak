The authoritative payloads are attempt002/oracle-80.json and oracle-110.json. Each contains 48 cases in approved plan order: 12 finite spacetime points, with epsilon0/.025/.05/.1 at each point. The two precision payloads retain decimal strings rather than rounded binary64 values. Coordinates and reference coefficients use the exact binary64 values specified by plan.json; Gaussian parameters use the exact decimal strings there.

Spacetime axes are (t,x,y,z). A Jet record has `order` and `ordinary`: each entry is a four-component `multiindex` and its ordinary derivative `value`. These are derivatives, not Taylor coefficients. Both time and spatial mixed coefficients are retained. No consumer may request a derivative whose total order exceeds `order`.

`physical_metric[a][b]` gives the physical four-metric through spacetime order2. `X`, `inverse_first/second/third` and `Yhat`, `reference_first/second/third` give the physical inertial inverse map and reference embedding through order3. First-map indices are [inertial component][coordinate derivative]; the later arrays append additional derivative indices. The metric signature is -+++.

`fields` contains Penrose `alpha`, contravariant Cartesian `beta[3]`, `chi`, conformal determinant-one `metric[3][3]`, external `omega`, stored trace-free `A[3][3]`, physical `P=Kphysical` and `Theta=Theta_physical=0`, and `Lambda[3]`. The time values are calculated from the same full metric jets and independently checked against retained coefficients; they have not been compared with a tensor RHS kernel.
