## Why restoration is retained

Removing the redundant collar is distinct from removing restoration. For a regular near-scri deviation beta+x = Omega*b1 + O(Omega²), the existing source tends to -4*b1. W=C=1 in a neighborhood of scri, so the shared transition preserves this finite limit and its normal derivatives exactly. Removing restoration would change both tangential shift evolution and the dependent normal D: with `a = a_base - 4*b1` and `D_normal = (normal_rate - a_normal)/mu`, the zero-restoration closure would need `D_normal_new = D_normal_old - 4*b1_normal/mu`. No evidence presently establishes that this different boundary system preserves accuracy/stability; restoration remains. This is a limiting-equation comparison, not proof that restoration is mathematically indispensable.

## Native initializer derivation to implement next

The shift integral can be evaluated without nesting a radius inversion inside quadrature. With R the physical areal radius on the monotone outer branch, A_r=−2R*s_R/(3*Omega), dr/dR=r/[R*sqrt(F+R²*s²)], and physical lapse alpha_phys=alpha_bar/Omega, the stored beta deviation divided by r is the integral from max(R,R0) to R1 of alpha_phys*s_R/sqrt(F+R²*s²) dR. For all inner isotropic points use the lower bound R0 (including the other wormhole end); outside R1 this integral is exactly zero. This follows from the existing −tail_integral(1.5*alpha_bar*A_r/r), but still requires numerical cross-validation before use. The native scri limit has chi=1 and all31 deviations zero except chi, matching the reference surface; initialize the actual surface explicitly.
